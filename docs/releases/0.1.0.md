# Stranger Enclave v0.1.0

The first versioned baseline brings the current localhost-tested bot into the stable release workflow. This release tracks [issue #5](https://github.com/azcoigreach/stranger-enclave/issues/5).

- Discover and remain within the starting 9×9 sector.
- Bootstrap into source mining, hauling, controller upgrading, storage and RCL 5 links.
- Scout, mine and reserve eligible adjacent rooms with economic and safety gates.
- Plan a defensive enclosure and future building capacity, rebuild recorded infrastructure, and fund progressive wall/rampart strengthening.
- Recover from controller traffic loops, incomplete remote routes and storage congestion.
- Display `[enclave:startup] Stranger Enclave v0.1.0 (tick …)` once after each runtime restart.

## Deployment

The attached ZIP contains all root JavaScript modules, including `version.js`; no bundling is required. Install the complete set into the chosen Screeps code branch. Update dependency modules before `main.js`, or use an atomic code upload where available. The repository's localhost script directory synchronizes edits immediately.

Memory schema remains 2. The software release version is separate from memory and planner schema versions. Do not clear Memory during an ordinary update. Existing perimeter replacement still requires matching approval. Rolling code back does not undo completed construction or demolition; restore a compatible module set and inspect persisted planner state.

## Validation and scope

The validation suite checks runtime imports/types, deterministic regressions, version consistency and separate-process replay. Startup coverage verifies one banner per runtime, renewed banners after resets, and logging even when initialization fails. Operational replay excludes only that intentionally reset-dependent banner; operational/error logs remain compared.

Live evidence for the base release is recorded under `docs/validation/`: source harvesting, traffic recovery, link energy flow, controller progress and remote reservation. Full player-raid defense, claiming, ranked remote selection, and RCL 6–8 live acceptance remain open. See [CHANGELOG.md](../../CHANGELOG.md) for the release scope and known limitations.
